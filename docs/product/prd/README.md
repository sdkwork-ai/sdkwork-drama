# PRD Directory

Canon product requirements for `sdkwork-drama`.

## Canon Directory Splitting Rules

- `PRD.md` is the single Canon entrypoint for product requirements. Do not
  fork requirement bodies into other files; extend PRD.md in place.
- Split supporting material (research notes, deck sources, meeting notes)
  into sibling subdirectories only when they are referenced from PRD.md;
  they are narrative context, not requirements authority.
- Global normative standards are never copied here — they stay in
  `../sdkwork-specs/` and are linked by relative path.
- Rewriting or deleting `PRD.md` requires human review per
  `../../AGENTS.md` Human Review Rules.

Related: `../../AGENTS.md`, `../../../sdkwork-specs/DOCUMENTATION_SPEC.md`.
