# Repository-Local Skills

Repository-local agent skills for `sdkwork-drama`.

Purpose: hold skills authored for this repository only (short-drama creation workflows, Rust backend conventions, local verification recipes).

Owner: sdkwork-drama maintainers.

Allowed: `SKILL.md` files with supporting assets, scoped to this repository.

Forbidden: global skills (belong in user/workspace-level skill directories), secrets, generated artifacts.

Related specs: `../sdkwork-specs/SDKWORK_WORKSPACE_SPEC.md`, `../sdkwork-specs/AGENTS_SPEC.md`.

Verification: `node ../sdkwork-specs/tools/audit-repository-baseline.mjs --root .`
