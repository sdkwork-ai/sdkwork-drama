# Repository-Local Plugins

Repository-local agent plugins for `sdkwork-drama`.

Purpose: hold plugins authored for this repository only.

Owner: sdkwork-drama maintainers.

Allowed: plugin manifests and authored plugin assets scoped to this repository.

Forbidden: global plugins, secrets, generated artifacts.

Related specs: `../sdkwork-specs/SDKWORK_WORKSPACE_SPEC.md`, `../sdkwork-specs/AGENTS_SPEC.md`.

Verification: `node ../sdkwork-specs/tools/audit-repository-baseline.mjs --root .`
