# examples/

Purpose: runnable examples demonstrating how to compose and consume the `drama` backend crates and SDK families.

Owner: sdkwork-drama maintainers.

Allowed: small self-contained examples that build with the workspace (`cargo build --workspace`) or run with repository tooling.

Forbidden: production code, secrets, untracked large assets.

Related specs: `../sdkwork-specs/SDKWORK_WORKSPACE_SPEC.md` (directory dictionary).

Verification: `cargo build --workspace`
